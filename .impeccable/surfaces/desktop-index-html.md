# Desktop shell

- Scope and mode: the main Windows desktop utility in Operate mode.
- Audience: people who want fast, private voice typing across their existing apps; a recruiter should understand the product in one viewport.
- Job and primary actions: verify readiness, use push-to-talk or hands-free dictation, see live words, cancel safely, and recover the previous result.
- Proof and content: live transcript state, recoverable local history, private-device usage totals, dictionary/snippets, and explicit local processing status.
- Constraints: background-first, keyboard and side-mouse accessible, minimum 760×600, no cloud dependency for transcription, and no fabricated usage data outside labeled E2E preview mode.
- Chosen direction: a quiet ink-and-cool-paper command workspace with a restrained cobalt action, flat divider-led topology, and compact native controls.
- Memorable moment: the visibly labeled Hands-free control and the compact floating recording bar make dictation mode obvious without taking over the screen.
- Unresolved: code signing and first-run model-download guidance remain release concerns rather than layout decisions.
